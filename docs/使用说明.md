# 身份证 / 银行卡 A4 打印工具 · 使用说明

双击 `身份证A4打印工具.exe` 即可，全部本地电脑处理，照片不出电脑。

> 版本 v1.0.0 · 开发者 一只小白 · <https://github.com/xiaobyes/idcard-a4-print>
> 程序界面右上角有 **「关于」** 按钮，点开可看版本、开发者，并一键打开或复制仓库地址。

## 一、最常用流程（3 步）

1. 把手机拍的照片**拖进窗口上方**（可以一次拖一张、也可以拖多张/整个文件夹；拖几次都行，列表会一直累加）。
2. 点 **「开始处理并生成 A4」**。
3. 右侧看到 A4 预览后，点 **「打印」**（在「打开 PDF」左边）→ 弹出打印设置（选打印机、选份数）→ 点「打印」直接出纸。全程不用打开任何 PDF 阅读器。

输出默认在程序同目录下的 `输出` 文件夹（不管从哪里打开程序都固定在那儿）：一个 A4 PDF + 一页预览 PNG。

## 二、照片要求（很宽松）

- 手机正常拍就行：**身份证、社保卡、银行卡、驾照、居住证**等任何 85.6×54mm 卡片都能处理。
- 正着拍、斜着拍、竖着拍、有桌面背景、有阴影都能自动抠出来并摆正。
- **卡没拍全、有一边跑到画面外面（但姓名、号码、照片这些信息都在）**也没关系：程序会按卡面信息把整张卡推算出来，缺的那一小截自动补上，状态显示 `已补齐`。
- 一张照片里如果同时有**正反两面**，会自动拆成两张卡。

## 三、每一行右侧的按钮

| 按钮 | 作用 |
|---|---|
| **▲ / ▼** | 上移 / 下移一位，决定这张卡在 A4 上排在前还是排在后。有结果时会按新顺序自动重排。第一位不能上移、最后一位不能下移（箭头是灰的）。 |
| **四角** | 自动框不准时手动点四个角。窗口里虚线框就是自动识别的位置，直接拖动圆点贴着卡边微调；右侧「矫正预览」实时显示最终结果。点完四个角→「应用并重新生成」，点完就立刻按新四角重算，不用再点「开始处理」。圆点拖不出画布，两个点贴太近会自动按矩形兜住，正常点不会失败。 |
| **方向** | 方向还是不对就点它：每点一次按 0°→90°→180°→270° 循环转，按钮上会显示当前角度，转完立刻重新生成。 |
| **✕** | 从列表里删掉这张照片。 |
| 状态标记 | `精确` 自动识别到位；`已补齐` 卡被画面切掉一截，程序按卡面内容把整卡补全了（缺角那一小条是用边缘像素延伸的）；`手动` 用了你定的四角；`未识别` 卡面和卡边都认不全（会弹窗提示，建议重拍或点「四角」）；`失败` 会弹窗写明原因并写日志。 |

> 小提示：一般不需要手动干预。只有「卡只入镜一部分」「反光严重」这类极端情况才需要「四角 / 方向」。

## 四、输出参数

- **输出内容**：`A4 打印页`（默认，只出 PDF）／`证件图片`（每张单独出 PNG，带透明圆角）／`A4+图片`（都出）。
- **排版方式**：`自动排版`（推荐）／`每张一页`／`两张一页`／`八张一页`。
- **卡片间距 mm**：默认 10，排得开就加，想省纸就减。
- **圆角半径 mm**：默认 3.18（和真身份证一致），填 0 就是直角。
- **自动增强**：自动去灰底、提亮、修掉阴影。
- **亮度 / 对比度**：处理完觉得发灰或偏暗，拖滑块实时重算；点右边的 **「亮度/对比度默认」** 一键回到 0 / 1.00。

生成的成品尺寸是真实的 **85.6×54mm**，300 DPI（1011×638 像素），打出来和真卡一样大。

## 五、打印是怎么打的

点「打印」→ 程序自己列出系统里所有打印机（默认打印机自动选中）→ 选份数 → 点「打印」。

- **直接调 Windows 打印**：程序用系统 GDI 把整页 A4 按 **1:1 真实尺寸（210×297mm）** 直接送进打印队列，不经过任何第三方阅读器，也不缩放。
- **打印机设置里只要把纸张选成 A4**，出来就是真实尺寸，身份证和真卡一样大（可以叠在真卡上比）。
- 打印机没装好、离线、缺纸时，程序会提示具体错误，不会假装打印成功。

> 如果你更习惯用阅读器自己打：点「打开 PDF」，在阅读器里按 Ctrl+P，记得选「实际大小 / 100%」。

## 六、命令行（批量用）

```
身份证A4打印工具.exe -o D:\输出 -f a4 "D:\照片\*.jpg"
```

- `-f a4`：只出 A4 PDF（默认）；`-f image`：只出证件图片；`-f both`：都出。
- 不加参数直接双击 = 打开界面。

## 七、常见问题

- **框出来还是歪的/倒的**：点该行的 **「方向」** 转 90°，或「四角」重新贴一下卡边。
- **顺序排错了**：点 **▲ / ▼** 调位置，程序会按新顺序重新排版。
- **一张照片出了两张卡**：照片里确实有两张卡（正反面），正常；只想要一张就把另一张删掉再用。
- **照片没识别到卡**：说明卡被压住、对比度太低或者严重反光。换一张拍全的照片，或用「四角」手动框。
- **卡有一边跑出画面了**：只要姓名、号码、照片都拍全，程序会自动补齐成整卡（状态 `已补齐`）；卡面信息也缺了一截就补不了，会提示 `未识别`，这时只能重拍或用「四角」。
- **两行都变红色「失败」**：程序会弹窗写清原因（同时写日志到 `%TEMP%\身份证A4打印_错误日志.txt`），把弹窗里的文字发我就能定位。最常见的是输出目录不可写——点「浏览」换到桌面再试。
- **打印出来偏大/偏小**：用程序里的「打印」不会偏；若自己用阅读器打，才需要选「实际大小 / 100%」。
